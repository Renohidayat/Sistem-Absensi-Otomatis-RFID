Keterangan Sequence Diagram:

Diagram sekuensial ini merincikan urutan waktu pesan/data yang dipertukarkan antara objek dalam sistem:

  • Menggambarkan garis hidup (lifeline) dari 5 komponen utama: Pengguna (Siswa), Hardware Pembaca (RFID), Hardware Otak (NodeMCU), Cloud (Firebase), dan Software Tampilan (Web).
  • Menunjukkan bahwa proses absensi di NodeMCU bersifat memblokir (menunggu response dari Firebase).
  • Pada langkah ke-7, terlihat fitur keunggulan Firebase di mana Aplikasi Web tidak perlu me-refresh halaman untuk meminta data (polling), karena Firebase otomatis mendorong (push/sync) data terbaru ke Web yang sedang terbuka.
