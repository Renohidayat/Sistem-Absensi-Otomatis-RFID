Keterangan Diagram:

  • Proses Pembacaan: Sistem standby membaca kartu. Jika terbaca, MCU akan mengecek konektivitas sebelum memproses.
  • Verifikasi: UID kartu dikirim ke Firebase untuk dicek apakah sudah diregistrasi. Jika belum, sistem menolak (Error).
  • Pencatatan: Jika kartu dikenali, sistem memvalidasi waktu saat ini untuk menentukan apakah absensi masuk, terlambat, atau pulang, dan menyimpan log ke dalam sistem.
  • Integrasi Web: Segera setelah database (Firebase) diperbarui, aplikasi web otomatis menampilkan data absensi terbaru secara realtime.
