Keterangan Struktur Database:

Sistem ini menggunakan NoSQL Database (Firebase Realtime Database), namun relasi logisnya digambarkan dalam ERD sebagai berikut:

  • Entity SISWA: Menyimpan biodata lengkap siswa dengan rfid_uid sebagai Primary Key untuk pengenalan cepat via perangkat keras.
  • Entity ABSENSI: Mencatat riwayat kehadiran (log). Setiap catatan terhubung ke tabel Siswa melalui Foreign Key rfid_uid. Tabel ini diperbarui dua kali dalam sehari (saat tapping masuk dan tapping pulang).
  • Entity PENGATURAN_JAM: Konfigurasi global yang dapat diatur admin untuk menentukan status absensi (misalnya kapan siswa dihitung terlambat).
  • Entity ADMIN: Menyimpan profil admin untuk autentikasi Dashboard web.
