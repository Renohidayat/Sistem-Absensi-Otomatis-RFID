Keterangan Use Case:

  • Aktor Siswa: Hanya memiliki interaksi fisik dengan perangkat keras yaitu melakukan proses pemindaian (tapping) kartu RFID untuk absensi.
  • Aktor Admin: Memiliki akses penuh terhadap aplikasi perangkat lunak. Admin berhak melihat statistik, mengelola data siswa, mendaftarkan kartu RFID, mengatur batasan jam, dan mengekspor laporan.
